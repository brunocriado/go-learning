## 🛠️ Setup & Configuration

Before starting any project, complete the environment setup:

**[→ Complete Setup Guide](getting-started.md#development-environment-setup)**

Quick setup checklist:
- [ ] Install Go 1.21+
- [ ] Configure Go environment (GOPATH, PATH)
- [ ] Install gopls, goimports, golangci-lint
- [ ] Set up editor (VS Code/GoLand/Vim)
- [ ] Install Docker
- [ ] Install PostgreSQL, Redis, MongoDB (for database projects)
- [ ] Configure Git
