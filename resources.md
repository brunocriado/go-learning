# Learning Resources & Community

A curated collection of books, courses, communities, and tools to accelerate your Go learning journey.

---

## 📚 Books

### For Beginners

**The Go Programming Language** by Alan Donovan & Brian Kernighan
- The definitive Go book
- Clear explanations with practical examples
- Covers fundamentals thoroughly
- ~$40 | [Amazon](https://www.amazon.com/Programming-Language-Addison-Wesley-Professional-Computing/dp/0134190440)

**Learning Go** by Jon Bodner
- Modern Go practices (Go 1.18+)
- Generics and latest features
- Practical, hands-on approach
- ~$50 | [O'Reilly](https://www.oreilly.com/library/view/learning-go/9781492077206/)

**Head First Go** by Jay McGavren
- Visual, beginner-friendly style
- Interactive learning
- Good for programming newcomers
- ~$45 | [O'Reilly](https://www.oreilly.com/library/view/head-first-go/9781491969540/)

### For Intermediate/Advanced

**Concurrency in Go** by Katherine Cox-Buday
- Deep dive into goroutines and channels
- Concurrency patterns
- Performance considerations
- ~$40 | [O'Reilly](https://www.oreilly.com/library/view/concurrency-in-go/9781491941294/)

**Go in Action** by William Kennedy
- Practical Go programming
- Real-world applications
- Community-recommended
- ~$45 | [Manning](https://www.manning.com/books/go-in-action)

**Cloud Native Go** by Matthew Titmus
- Building cloud-native applications
- Microservices, Docker, Kubernetes
- Modern architecture patterns
- ~$50 | [O'Reilly](https://www.oreilly.com/library/view/cloud-native-go/9781492076322/)

### For Systems Programming

**The Linux Programming Interface** by Michael Kerrisk
- Not Go-specific but essential for systems work
- In-depth Linux/Unix programming
- Reference for Projects 11-21
- ~$75 | [No Starch Press](https://nostarch.com/tlpi)

**Network Programming with Go** by Adam Woodbeck
- TCP/IP, HTTP, WebSockets
- Network protocols in Go
- Relevant for Projects 8, 15, 26
- ~$50 | [No Starch Press](https://nostarch.com/networkprogrammingwithgo)

## 🛠️ Tools & Libraries

### Development Tools

**gopls** - Official Go language server
```bash
go install golang.org/x/tools/gopls@latest
```

**golangci-lint** - Fast linters aggregator
```bash
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest
```

**goimports** - Auto-format and fix imports
```bash
go install golang.org/x/tools/cmd/goimports@latest
```

**gotests** - Generate table-driven tests
```bash
go install github.com/cweill/gotests/gotests@latest
```

**air** - Live reload for Go apps
```bash
go install github.com/cosmtrek/air@latest
```

### Essential Libraries

**Web Frameworks:**
- [Gin](https://github.com/gin-gonic/gin) - Fast HTTP web framework
- [Echo](https://github.com/labstack/echo) - High performance, minimalist
- [Fiber](https://github.com/gofiber/fiber) - Express-inspired framework
- [Chi](https://github.com/go-chi/chi) - Lightweight, composable router

**Database:**
- [GORM](https://gorm.io/) - ORM library
- [sqlx](https://github.com/jmoiron/sqlx) - Extensions to database/sql
- [pgx](https://github.com/jackc/pgx) - PostgreSQL driver

**Testing:**
- [testify](https://github.com/stretchr/testify) - Testing toolkit
- [gomock](https://github.com/golang/mock) - Mocking framework
- [httptest](https://pkg.go.dev/net/http/httptest) - Built-in HTTP testing

**Logging:**
- [zerolog](https://github.com/rs/zerolog) - Fast, structured logging
- [zap](https://github.com/uber-go/zap) - Uber's fast logger
- [logrus](https://github.com/sirupsen/logrus) - Structured logger

**Configuration:**
- [viper](https://github.com/spf13/viper) - Complete configuration solution
- [godotenv](https://github.com/joho/godotenv) - Load .env files

## 🎓 Career Paths

### Entry-Level (0-2 years)

**Titles:**
- Junior Go Developer
- Backend Developer (Go)
- Software Engineer I

**Focus:**
- Complete Basic + Intermediate projects (1-18)
- Build portfolio with 3-5 deployed projects
- Contribute to open source
- Learn one cloud platform (AWS/GCP)

**Salary Range:** $60k-$90k USD

### Mid-Level (2-5 years)

**Titles:**
- Go Developer
- Senior Backend Developer
- Software Engineer II

**Focus:**
- Complete Advanced + Expert projects (19-30)
- Master distributed systems
- Lead small projects
- Mentor juniors

**Salary Range:** $90k-$140k USD

### Senior-Level (5+ years)

**Titles:**
- Senior Go Engineer
- Staff Engineer
- Tech Lead

**Focus:**
- Complete Specialized projects (31-35)
- Design system architecture
- Performance optimization
- Team leadership

**Salary Range:** $140k-$200k+ USD

## 🌟 Final Words

**Go is growing rapidly:**
- Used by Google, Uber, Dropbox, Netflix, Docker, Kubernetes
- High demand, competitive salaries
- Great for cloud-native applications
- Strong community support

**Your learning journey:**
1. **Months 1-3**: Foundations (Projects 1-6)
2. **Months 4-8**: Backend skills (Projects 7-18)
3. **Months 9-15**: Advanced topics (Projects 19-30)
4. **Months 16-20**: Specialization (Projects 31-54)

**Remember:**
- Consistency beats intensity
- Build real projects
- Join the community
- Share what you learn
- Never stop learning

---

**You won't become a master in 6 months. But in 12 months, you'll be dangerous. In 18-24 months, you'll be irreplaceable.**

Good luck on your Go journey! 🚀
