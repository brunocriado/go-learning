## 📋 Key Constraints from AGENTS.md

### When Creating/Editing Project Files:

**DO:**
- ✅ Extract complete content (300-800 lines per project)
- ✅ Include: Overview, Prerequisites, What You'll Learn, Core Features, Implementation Guide, Code Examples, Task Checklist
- ✅ Add navigation links (← Back | ↑ Up)
- ✅ Create task checklists that guide WITHOUT providing solutions
- ✅ Use multi_replace_string_in_file for batch operations

**DON'T:**
- ❌ Create placeholder files
- ❌ Summarize or omit implementation details
- ❌ Provide solutions in task checklists
- ❌ Use absolute paths (use generic placeholders)
- ❌ Include sensitive information (usernames, paths)

### Task Checklist Standards:

- Break into phases (Setup → Implementation → Testing → Refinement → Bonus)
- 50-120 tasks total depending on project level
- Ask guiding questions, don't provide answers
- Include debugging questions section
- Format: `**Task X.Y**: [Action verb] [specific goal]`
